# Лабораторна робота №2. Дослідження засобів канального рівня моделі OSI. Протокол ARP

## Тестове оточення

| Параметр | Значення |
|---|---|
| ОС | Ubuntu 24.04 LTS (VirtualBox 7.2, адаптер NAT) |
| Тестований вузол | enp0s3, IP 10.0.2.15/24, MAC 08:00:27:e1:b0:56 |
| Віддалений вузол | шлюз NAT 10.0.2.2, MAC 52:54:00:12:35:00 |
| Інструменти | Wireshark 4.6.9, arp (net-tools), ip neigh, ping |

## Тест-кейси

| ID | Назва | Статус | Файл захоплення |
|---|---|---|---|
| TC-ARP-00 | Отримання MAC-адреси за відомою IP-адресою | PASSED | `tc0_mac_by_ip.pcapng` |
| TC-ARP-01 | Оновлення ARP-таблиці при отриманні ARP reply (основний) | PASSED | `tc1_arp_update.pcapng` |
| TC-ARP-02 | Статичний запис в ARP-таблиці, ping без ARP-запитів | PASSED | `tc2_static_arp.pcapng` |
| TC-ARP-03 | ARP-запит до неіснуючої адреси 10.0.2.99 (власний) | PASSED | `tc3_no_reply.pcapng` |

Файли `.pcapng` відкриваються у Wireshark (File → Open). Для перегляду ARP-обміну застосуйте фільтр `arp` (для TC-ARP-02 – `arp || icmp`).
